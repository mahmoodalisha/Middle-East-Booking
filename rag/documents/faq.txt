Middle East Booking - Frequently Asked Questions

What is Middle East Booking?
Middle East Booking is a hotel booking application that allows users to browse hotels, view rooms, check room availability, and create bookings.

What information is available for hotels?
Hotels have information such as their name, type, city, address, distance, description, rating, cheapest price, photos, and whether they are featured.

What types of properties are supported?
The application currently supports hotel, apartment, resort, villa, and cabin property types.

Can I search hotels by city?
Yes. Hotels can be filtered by city.

Can I search hotels by price?
Yes. Hotels can be filtered using a minimum and maximum price range based on the hotel's cheapestPrice.

Can I view featured hotels?
Yes. The application supports filtering hotels using the featured property.

Can I view the rooms available at a hotel?
Yes. A hotel is associated with its rooms, and the application can retrieve the rooms belonging to a particular hotel.

What information does a room have?
A room has a title, price, maximum number of people, description, physical room numbers, and unavailable dates.

What is a physical room number?
A physical room number represents an actual room belonging to a particular room type. Each physical room maintains its own unavailable dates.

Why might a room be unavailable?
A physical room is unavailable when one or more dates for that room have already been reserved by an existing booking.

Can two users book the same room for the same date?
The booking system checks the room's unavailable dates before creating a booking and rejects a booking when a date conflict is detected.

Does the application use database transactions for bookings?
Yes. Booking creation uses a MongoDB transaction to coordinate room availability updates and booking creation.

Can I see whether a booking is paid?
A booking contains an isPaid field that indicates its payment status. New bookings are initially marked as unpaid.
